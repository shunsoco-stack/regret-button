## ポートフォリオ文

### タイトル

後悔ボタン — 何も起きない操作を、ひとつの体験に。

### 紹介文

「押さないでください」と書かれた赤いボタン。押しても何も起きません。ただ、少しだけ気まずい言葉が返ってきます。

後悔ボタンは、好奇心とUIの関係をテーマにした小さなWebアプリです。押す回数に応じて変化するメッセージ、長押しで入る「より深い後悔」、100・500・1000回の節目を通じて、単純な操作に変化を持たせました。

研究施設の操作盤を思わせるダークな画面と、立体感のある赤いボタンをデザイン。視覚・短い振動・Web Audio APIで合成した音を組み合わせつつ、音は初期状態でオフにし、動きを減らす設定やキーボード操作も考慮しています。

端末内の累計・本日の回数・前回の時刻はlocalStorageに保存します。「取り消せません」という冗談とは別に、設定には実際に記録を消せるリセットを用意。課金、強制的な外部移動、位置情報などへのアクセスはありません。

### 技術と工夫

- Next.js / TypeScript / Tailwind CSSで、モバイルを中心に設計。
- Web Audio APIで効果音を生成し、既存の音源ファイルを使用しない構成。
- Vibration APIは対応端末でのみ使用。音・振動・動きは設定で調整。
- Reduced Motionに対応し、ボタンがわずかに逃げる演出も無効化可能。
- PWA向けのmanifestとオリジナルアイコンを用意。
- Vercel Analytics向けに通常押下・長押し・共有・節目のイベント送信を実装。任意の累計回数や時刻、独自の識別子は送信しない設計。現在のHobbyプランではカスタムイベントの集計・閲覧にPro以上が必要です。

## Tsukutta文

### タイトル

後悔ボタン — 押しても、何も起きません。

### 本文

「押さないでください」。そう言われると、押したくなりませんか。

大きな赤いボタンを押すと、「本当に押したんですね」「特に何も起きません」と、ちょっとだけ後悔する言葉が返ってくるWebアプリをつくりました。

押した回数に合わせて言葉が変わり、長押しすると「より深い後悔」モードに。100・500・1000回では特別な演出もあります。累計や本日の回数はこの端末に保存され、設定からリセットできます。

見た目は少し危険そうな研究施設。でも、ボタンを押して起きるのは画面上の冗談だけです。音は初期状態でオフ。課金も、位置情報の取得もありません。

何も起きないことを、よかったら確かめてみてください。

アプリ：https://regret-button.vercel.app

GitHub：https://github.com/shunsoco-stack/regret-button

## YOUTRUST投稿文

「何も起きないボタン」を、どこまで触りたくなるUIにできるか。

そんなテーマで「後悔ボタン」をつくりました。

押すたびに少し気まずいメッセージが返ってくる、小さなWebアプリです。赤いボタンの立体感、押した瞬間の反応、長押しで変わる空気感など、操作の手触りを意識しました。

Next.js / TypeScript / Tailwind CSSで実装。効果音はWeb Audio APIで生成し、Reduced Motionやキーボード操作、設定からの本当のリセットも用意しています。

便利さではなく、「つい触ってしまう体験」を考えるきっかけになりました。よかったら、一度だけ押してみてください。

https://regret-button.vercel.app
